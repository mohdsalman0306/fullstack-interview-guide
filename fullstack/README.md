# Start here: Full Stack Interview Study Files

The big guide is now split into small files. **Pick one file, finish it, tick it off below.**
Each file has its own checklist at the top so you always know where you stopped.

> The original full guide is still here: `../Senior_Full_Stack_Interview_Bible_v2.md` (nothing was deleted).

## How to study one file
1. Open the file and look at its **Progress checklist**.
2. For each question, read **In simple words**, then say the **🗣️ Say this** answer **out loud**.
3. Tick the box `[x]` when you can say it without looking.
4. At the end, read **Remember these 10 things**.
